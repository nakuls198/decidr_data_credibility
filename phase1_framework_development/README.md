# Phase 1 — Framework Development

This is the first release of materials on Northfield Software Ltd. It contains:

- Company overview, org chart (current and a superseded prior version), role descriptions, and a decision-rights table (`00_overview/`)
- All current policies (`02_policies/`)
- All current process documents (`03_process_docs/`)
- Three employee interviews (`04_interviews/`)
- A small sample of labelled reference claims (`labelled_claims_sample.csv`), included only to show the format a knowledge claim and its assessment might take

## What to do with this

Using only these materials, define what you consider an organisational knowledge claim, and propose your criteria and methodology for assessing the credibility of a claim. You will receive further materials in later phases.
